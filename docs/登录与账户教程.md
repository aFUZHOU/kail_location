# 登录与账户教程

> 模拟功能支持**游客模式**：未登录用户无需注册/登录即可使用，每位游客自动获得 **100 次免费模拟机会**
> （次数用尽后引导登录/注册，详见《游客模式设计方案》）。登录方式：**邮箱 + 验证码**
> （仅支持 QQ 邮箱与谷歌邮箱，注册与登录一体——没有注册页，首次登录即自动注册）。

## 1. 登录

### 入口

侧边栏 ☰ 头部：未登录显示 **「未登录」** → 点击进入登录页。

### 步骤

1. 登录页标题「账户」，副标题提示"仅支持 QQ 邮箱与谷歌邮箱，输入验证码即可登录或自动注册"；
2. 输入 **邮箱地址**（支持 `@qq.com` / `@gmail.com`，大小写不敏感）；
3. 点 **「发送验证码」**：本应用/邮箱会收到 6 位验证码（如未收到，检查垃圾邮件，稍后重试）；
   - 邮箱为空 → "邮箱不能为空"；域名不支持 → "仅支持 QQ 邮箱（@qq.com）与谷歌邮箱（@gmail.com）登录，请更换邮箱后重试"；
4. 输入验证码（数字键盘），点 **「登录 / 注册」**；
5. 成功后自动跳到「个人主页」，侧边栏头部显示登录邮箱。

## 2. 个人主页

点击侧边栏头部的邮箱（已登录时）进入：

- **邮箱地址**：当前账号邮箱；
- **会员状态**：已订阅 / 未订阅（未订阅时显示 **「订阅会员」** 按钮 → 跳转订阅页）；
- **退出登录**（红色）：清除本地登录与订阅凭证（不影响已付款的订阅关系）。

## 3. 后续各功能的门控

| 功能 | 登录要求 |
| --- | --- |
| 位置/路线/导航模拟、NFC 发送、WiFi/基站/摄像头模拟 | 游客 100 次免费（未登录）；登录后需订阅或会员免费次数（开始或启动时校验） |
| 独立模拟开启 | 游客 100 次免费（扣 1 次）；登录后需免费次数 |
| Root 应用隐藏、沙盒 | 无登录要求 |
| 订阅/套餐列表、FAQ | 订阅页需登录；FAQ 无需登录 |

## 3.1 游客模式

- 未登录时抽屉头部与主界面显示"游客模式 · 剩余 N 次"；
- 每次"开始模拟"扣 1 次，共 100 次，服务端记录（断网按本地记录扣减，联网后自动对账）；
- 次数用尽弹"登录 / 注册"引导框，也可从抽屉头部随时登录；
- 退出登录不会重置游客次数（同一设备 continuity），防止反复登出刷次数。

## 4. 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 收不到验证码 | 确认邮箱正确（支持 qq/gmail）；等 1 分钟再点；检查垃圾箱；不要频繁点击 |
| 验证码过期 | 重新点「发送验证码」获取新的 |
| 提示域名不支持 | 换成 @qq.com 或 @gmail.com 邮箱 |
| 登录后还提示未登录 | 检查网络；重启 App；确认服务端可用 |
